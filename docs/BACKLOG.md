# Backlog

## Adiamento (pedido na validação da Etapa 1, adiado por decisão do usuário)
- "Amanhã" deve usar o mesmo horário da tarefa; sem horário, 09:00.
- Opção para escolher uma data/hora mais à frente (útil para tarefas em EM BREVE).

## Pequenos
- Seletor de data do Flutter pode começar a semana no domingo; a regra do app é segunda.
